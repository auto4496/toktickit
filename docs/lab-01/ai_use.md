# Lab 1 - AI Use and Reflection

I used OpenAI Codex in the Codex desktop application with a GPT-5 model. I used it as a coding assistant for Git troubleshooting, implementation, peer-review support, testing, and documentation. I reviewed the suggested changes, ran the commands in my own environment, and decided whether each result was valid before accepting it.

## Reflection

My early prompts were often too short because I assumed that the previous chat context was enough. The results improved when I included the current branch and base branch, the exact Issue scope, files that must be preserved, required response values, expected evidence, and complete command output. I also learned to verify AI findings instead of accepting them immediately. During one peer review, a restricted environment produced a Prisma-related failure that did not occur in a clean installation. After my partner supplied reproducible results, I corrected the review. The most reliable workflow was to compare each suggestion with the Lab acceptance criteria and confirm it using tests, builds, Git diffs, database checks, and browser behavior.
